# 🍔 Massinissa Restaurant — React Frontend

مشروع React كامل لمطعم **Massinissa** مبني بـ Vite + React Router + Context API.

## 🌟 المميزات
- **نفس التصميم والألوان الأصلية 100%**: تصميم داكن أنيق (كحلي + أحمر/برتقالي + ذهبي) مع خطوط Cairo و Playfair Display SC و Karla.
- **دعم 3 لغات**: العربية (RTL)، الفرنسية، والإنجليزية.
- **مسار سري للمدير (Hidden Route)**: لا يوجد أي رابط له في واجهة الزبائن.
  - يدخل المدير يدوياً بكتابة: `/manager` في المتصفح.
  - يطلب منه اسم المستخدم وكلمة المرور.
- **لوحة تحكم إدارية (Manager Dashboard)**:
  - إضافة أطباق جديدة إلى القائمة وتحديد الصور والأسعار والتصنيفات (برغر، ساندويتش، تاكوس، وغيرها).
  - إمكانية رفع صورة جديدة أو الاختيار من الصور المحملة مسبقاً.
  - تعديل الأسعار وحذف الأطباق وحفظها فورياً في `localStorage`.
  - إمكانية استرجاع القائمة الافتراضية بنقرة واحدة.

## 🚀 طريقة التشغيل:
```bash
cd Frontend
npm install
npm run dev
```
ثم افتح الرابط: `http://localhost:5173/`
وللوصول للوحة الإدارة: `http://localhost:5173/manager`
