# 🍔 Massinissa — Pizzeria & Restaurant

A modern, responsive website for **Massinissa** restaurant featuring burgers, sandwiches, tacos and more.

## ✨ Features

- 🌐 **Multilingual** — English, French & Arabic (full RTL support)
- 📱 **Fully Responsive** — looks great on all screen sizes
- 📍 **Google Maps** — embedded map with directions link
- 🎨 **Modern Design** — dark theme with smooth animations
- ⚡ **No Dependencies** — pure HTML, CSS & JavaScript

## 📁 Project Structure

```
Massinissa/
├── index.html              # Main page
├── style.css               # All styles
├── script.js               # i18n & animations
├── Assets/
│   └── Pictures/
│       ├── Burger/         # Burger images
│       ├── Sandwich/       # Sandwich images
│       └── Tacos/          # Tacos images
└── README.md
```

## 🚀 Getting Started

Simply open `index.html` in your browser — no build tools needed.
